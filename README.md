# Kirti Thakur | Data Analytics Portfolio

Open `index.html` in a browser (needs internet for the fonts and three.js CDN).

- `css/style.css` styles and theme colours (`:root` variables)
- `js/main.js` content data (skills, statistics, projects) and all interactions
- `assets/` your photos: replace `kirti-cutout.webp` (transparent PNG/WebP, waist-up) and `about.jpg`

Host free with GitHub Pages: push this folder to a repo, Settings > Pages > deploy from `main`.
